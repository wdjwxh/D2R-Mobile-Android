# 个人测试预览 APK

个人测试包放在仅仓库管理者可见的 **Draft Release（草稿发布）**，不作为公开游戏下载。需要在手机浏览器登录有权限的 GitHub 账号，打开提供的草稿页面后下载 APK。普通访客看不到草稿或其附件。

## 覆盖安装

- 应用 ID 保持 `local.d2rm`，预览版本为 `0.1.0-preview.1` / versionCode `101`。
- 测试包沿用原开发工作区的调试签名；不要改用隔离构建自动生成的另一把签名。
- 手机下载 APK 后直接覆盖安装，不先卸载。若系统提示签名冲突，停止并核对原签名，避免卸载损失数据。
- 基础游戏资源仍读取 `/sdcard/Android/data/local.d2rm/files/romfs/data/`。已有文件无需移动或重传，原应用私有 `save/` 路径不变。

## 首次 Vulkan 准备

设备启动时显示常用 Vulkan 管线准备进度，在手机 GPU 驱动上创建管线并保存设备缓存。GPU、驱动、资源输入或缓存有效性变化会触发重新准备。

这次直装测试包保留创建管线所需的 **SPIR-V 输入**，不携带另一台设备编译好的 GPU 缓存。SPIR-V 是本机从游戏 shader 翻译出的中间输入；它与已经为特定 Adreno 编译好的机器码不是一回事。原始 Switch shader 不能直接交给 Vulkan 编译。

预热参考上游的常用管线清单，但 Metal 的 PSO 记录不包含全部 Vulkan 固定状态，因此普通 graphics 预热是代表性管线，不冒充每个游戏绘制状态的精确缓存命中。未覆盖变体仍在首次使用时按需编译；不承诺此页消除所有场景卡顿。

部分预热失败时会明确提示，可以重试或选择继续按需编译；必要输入、档案或设备不可用时不会假装准备完成。

## 可选外部着色器档案

应用也支持从以下位置导入自己生成的兼容 SH4 档案：

```text
/sdcard/Android/data/local.d2rm/files/shaders/graphics.vkpack
```

或在准备失败页面通过系统文件选择器导入。档案验证并原子复制至私有目录后再使用。当前直装包不需要你额外操作这一项；基础 `romfs/data` 不能代替此 Vulkan 档案。

## 测试范围

请重点检查首次准备页、二次启动缓存复用、营地帧率与触控移动。小米 17 的最终原生性能仍需要实际反馈，模拟器数字不能当作手机保证。记录卡住的阶段或错误文字即可，不要公开上传游戏文件、存档或未脱敏日志。
